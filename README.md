# Plumbing website demos

Personalized homepage demos prepared by Walter Andrzejewski of Raze Designs for outreach to local plumbers near Fulshear, TX (ZIP 77441).

These are **not** official websites for the businesses listed. Each page includes `<meta name="robots" content="noindex">`, and `robots.txt` disallows crawling.

Each business has four styles at `/<slug>/v1/` through `/<slug>/v4/`. Visiting `/<slug>/` redirects to the style originally assigned to that shop.

- `v1` Classic — navy / teal / orange brochure layout
- `v2` Modern — dark navy and bright teal, rounded cards, quote form
- `v3` Emergency — dispatch / call-now
- `v4` Family — warm, neighborly, book-a-visit

Prices, reviews, hours, and dispatch status that are not taken from the business's public Google listing are labeled as sample content.

Hosted on GitHub Pages.
