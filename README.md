# Plumbing website demos

Personalized homepage demos prepared by Walter Andrzejewski for outreach to local plumbers near Fulshear, TX (ZIP 77441).

These are **not** official websites for the businesses listed. Each page includes `<meta name="robots" content="noindex">`, and `robots.txt` disallows crawling.

Templates: `v1-original` (classic brochure), `v3-emergency` (dispatch / call-now), `v4-family` (warm, neighborly). Prices, reviews, hours, and dispatch status that are not taken from the business's public Google listing are labeled as sample content.

Hosted on GitHub Pages.
